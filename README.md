# Darsh Garg

I build machine-learning products and the systems behind them.

My work spans data pipelines, retrieval, recommendation, decision-making under uncertainty, and guardrails for software agents. I care about clear problem definitions, strong baselines, reproducible evaluation, and systems that fail honestly.

[Website](https://darshgarg.com/) · [Résumé](https://darshgarg.com/cv) · [LinkedIn](https://www.linkedin.com/in/darshgarg13579/) · [Email](mailto:darsh.garg@gmail.com)

## Selected projects

- **[Bouncer](https://github.com/darshgarg7/Bouncer)** — A reference monitor that applies deterministic policy checks and independent state-delta verification to agent actions.
- **[Recommender Lakehouse](https://github.com/darshgarg7/Recommender-Lakehouse)** — A Databricks recommender system for cold-start marketplaces, from replay-safe data and point-in-time features through retrieval, training, and promotion gates.
- **[Tortus](https://github.com/darshgarg7/Tortus)** — A local-first retrieval engine that combines semantic search with bounded graph traversal and returns the evidence path behind an answer.
- **[Agentic Procurement](https://github.com/darshgarg7/AgenticProcurement)** — A Bayesian decision system that chooses whether to buy, ask, wait, or search under uncertainty.

More: [CausalOps](https://github.com/darshgarg7/CausalOps) · [MCP Reputation Policy](https://github.com/darshgarg7/MCP-Reputation-Policy)
